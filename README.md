# Pricing plan page · prototype

A clickable prototype of a pricing plan page that shows how far one plan is from invoicing and what to do next, from draft to archived.

Live: https://artskw.github.io/bf-recompose/
Sketch: https://artskw.github.io/bf-recompose/sketch.html

States:
[draft](https://artskw.github.io/bf-recompose/#/draft) ·
[ready to bill](https://artskw.github.io/bf-recompose/#/ready-to-bill) ·
[scheduled](https://artskw.github.io/bf-recompose/#/scheduled) ·
[active](https://artskw.github.io/bf-recompose/#/active) ·
[needs attention](https://artskw.github.io/bf-recompose/#/needs-attention) ·
[archived](https://artskw.github.io/bf-recompose/#/archived)

Built with React, TypeScript, Tailwind and shadcn/ui. Source available on request.
